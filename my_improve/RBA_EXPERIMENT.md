# DSQC + RBA 实验计划

2026-09-08。状态：实现与数值测试已完成，尚未进行正式训练；不能承诺精度提升。

## 1. 改什么，为什么

当前候选为 `DSQC + Relative Boundary Alignment`（相对边界对齐，RBA）。
DSQC 的代码、结构与超参数保持不变，仍正常训练其权重；QLCS 与其他历史候选关闭但保留代码。
RBA 是训练期几何正则，不是新增推理头，也不是 QCR 的更名。

最近六组验证分析（baseline 与 DSQC，种子 18/2026/3407）提示：

- DSQC 的误检包含较多定位不合格的预测，并非都能通过降低或提高分数解决。
- DSQC 三个种子的定位误检中，相对其最大 IoU 真值框，预测面积较大的数量分别为
  11/16、10/15、12/16。但不能据此假设所有预测框都应缩小。
- 若高置信度框覆盖了过大的厂区，而 IoU 合格的候选分数很低，单纯压分可能同时损害召回。
  本次假设是：直接减少相对边界误差，有机会使部分定位误检越过 IoU=0.5，改善 AP50/F1。
- 这只是实验假设。匹配框上的回归正则不能保证纠正未匹配查询的背景误检、重复框、
  或模型未学会的厂区边界语义；也不能根据先前失败的汇总指标断言其失败机制。

RBA 不读取验证/测试图像编号、错误列表或分析 JSON；训练时仅使用当前训练批次已有真值。
不修改冻结数据集、标注范围、数据划分和已有增强；不引入 NMS，不更改置信度阈值。

## 2. 文献依据与边界

- [D-FINE，ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/hash/6cf58a87e3097e7d1f9be3e8693a93de-Abstract-Conference.html)：
  原网络已包含 FDR 和 GO-LSD。此次保持其结构和监督定义，在末层框上添加小权重约束。
- [DEIM，CVPR 2025](https://openaccess.thecvf.com/content/CVPR2025/html/Huang_DEIM_DETR_with_Improved_Matching_for_Fast_Convergence_CVPR_2025_paper.html)：
  通过 Dense O2O 和 Matchability-Aware Loss 改善匹配监督。本次参考其关注监督质量的方向，
  但没有实现或复现 DEIM/MAL；为保持可归因性，本轮不同时修改增强和分类损失。
- [Unbiased Regression Loss for DETRs，2024 年预印本](https://arxiv.org/html/2410.22638v1)：
  Sized L1 按真值宽、高归一化回归误差。这是本方案尺寸归一化的直接相关来源；
  当前没有核实其顶会/顶刊录用，不能将其标为顶会论文。

本地 RBA 与 Sized L1 的差别：采用 `xyxy` 四边误差和 SmoothL1，附加而非替换原损失；
仅作用于末层/GO 分配一致的普通查询；设置尺寸下限和渐进权重。
这些是为本仓库做的适配，尚不代表已证明的独创性或优于已有方法。
论文不能把“RBA”写成某篇顶会论文的原模块，也不能仅凭换名宣称新损失。

## 3. 精确定义

对最终普通查询一对一匹配 `(q,g)`，仅当 D-FINE 原 GO 回归集合对同一查询也分配给
同一真值 `g` 时施加 RBA。匹配不一致则跳过，不更改任何原匹配结果。
这是“分配一致”筛选，不等于经过验证的高质量或正确匹配。

将预测和真值的归一化 `cxcywh` 转成 `xyxy`，令真值宽、高为 `w,h`：

```text
d = [max(w, 0.05), max(h, 0.05), max(w, 0.05), max(h, 0.05)]
e = (pred_xyxy - gt_xyxy) / d
L_RBA = sum_{selected pairs}(mean_{4 edges}(SmoothL1(e, beta=0.1))) / N_GT
lambda(t) = 0.2 * clip((epoch + step / epoch_step) / 5, 0, 1)
L_total = L_original_DFINE + lambda(t) * L_RBA
```

`N_GT` 复用原 criterion 中跨进程平均后的真值数量，下限为 1。
不按筛选后数量重新归一化，避免只有少数匹配时它们被额外放大。
0.05 是归一化尺寸的分母下限，不是删除小框的阈值；512 输入下对应 25.6 像素。
该下限也意味着极小尺寸区间不再严格尺度不变。

损失同时纠正框过大、过小和位置偏移，不使用只缩框的先验。
真值及日志统计不传播梯度；预测几何用 FP32，越界预测不裁剪，以保留纠偏梯度。
RBA 只在训练末层普通查询上计算一次，不加入重复遍历的 `losses` 列表，因此没有
RBA 辅助层、编码器或去噪损失。新增末层损失仍会通过共享网络正常反向传播。
VFL、L1、GIoU、FGL、DDF 的原定义和权重均不变；这不意味着训练后的原损失值不会变化。

空目标/无一致匹配时返回可反传的零。非有限预测或 RBA 损失明确报错；异常真值计入
`invalid_targets` 并跳过 RBA（不能依靠此功能容忍或修复整个原损失流程中的坏标注）。

## 5. 如何确认真正参与训练

日志 / TensorBoard `RBA/*` / `log.txt` 中可查看：

| 字段（终端前缀 `rba_`） | 含义 |
|---|---|
| `eligible` | 最终一对一匹配数，筛选前 |
| `selected` / `conflicts` | 分配一致且几何有效的数量 / 不一致数量 |
| `invalid_targets` | 一致匹配中无效真值数量，正常应为 0 |
| `raw` / `weighted` | 原始 RBA / 真正加入总损失的 RBA |
| `scale` | 当前渐进权重；epoch=0 第一个 step 为 0，epoch=5 达 0.2 |
| `relative_edge_error` | 选中框的平均绝对相对边界误差 |
| `oversize_fraction` | 选中预测面积超过真值的比例，并非误检率 |
| `bbox_ratio` | 加权 RBA 与原末层加权 L1 的数值比，不是梯度贡献比例 |

无目标的某个批次 `selected=0` 正常。前几轮检查总体 selected 不持续为零、
weighted 在 ramp 启动后非零且有限、invalid_targets=0。不能仅凭某一项损失下降判断 AP50/F1 上升。
多卡显示的是进程间平均计数；当前测试覆盖单卡，未进行实际多卡训练。

## 6. 固定实验方案，减少无效重跑

1. 首轮固定 SD3407，完整沿用 150 轮和原选权重规则；前 5～10 轮仅排查实现/数值问题，
   不根据早期 AP50 峰值武断停止。直接对照仅 DSQC 的 SD3407，而非更弱的旧三模块。
   同口径验证参考：AP50=0.9416、F1=0.8636（原始 JSON 保留全精度）。
2. 首轮是探索性筛选，不是论文结论。若完整训练后 AP50 和 F1 都比同种子 DSQC 低
   超过 0.005（0.5 个百分点），本候选不再追加两个种子，以节省预算；记录此筛选规则。
   这是工程止损线，不是统计检验。其余情况再固定同配置跑 18、2026，不在中间调超参数。
3. 论文保留以三种子配对结果为准：AP50、F1 均值都必须提高，至少两个种子同向改善；
   同时报告全部种子的 P/R、AP75、mAP50:95、均值与样本标准差，不筛掉较差重训结果。
   理想工程目标为 AP50/F1 各提升至少 0.003（0.3 个百分点），不是预期收益承诺或显著性证明。
   若平均 R 降低超过 0.010，应单列权衡，不宣称全面提升。
4. 所有比较使用同一个 checkpoint 的整套指标，例如各组按验证 AP50 选择的 `best_map50.pth`。
   不把 best_map50 的 AP50 与另一个 best_f1 的 F1 拼成一行。阈值固定 confidence=0.5、match IoU=0.5；
   最优 F1 阈值扫描仅作诊断，不能只给候选调阈值来证明模块收益。
5. 候选通过后补 `rba` 单模块三种子，形成四组完整消融。RBA 权重/筛选消融另列，
   不与主比较混合平均。若不通过则保留 DSQC，不为了凑创新点强行保留失败候选。

本轮所有选择限于训练/验证数据。此前测试结果已影响过方案去留，旧测试集不能宣称完全未参与开发；
保持现有冻结数据不动并如实披露限制，有条件时使用额外未查看数据作最终外部验证。
