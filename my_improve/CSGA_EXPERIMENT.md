# CSGA：跨尺度引导对齐（第三改进候选）

本轮保留 QLCS 和 DSQC 的实现、超参数及原始损失，改动 HybridEncoder 的两处
自顶向下上采样。当前 `IMPROVEMENT_MODE = "qlcs_dsqc_csga"`；旧第三模块全部关闭。
这是一个新的实验假设，不是已经验证有效的模块，也不保证论文录用或创新性成立。

## 为什么换到特征融合位置

最近 QCR 验证均值 AP50/P/R/F1 为0.9229/0.8223/0.8767/0.8486，而既定
QLCS+DSQC参照为0.9224/0.8181/0.8869/0.8509。P略升没有转化为F1提升，且
不同种子方向不一致。QACG、SHEA等也没有支持保留；不能因有个最好种子就认定有效。

此前方法的失败只说明这些配置未满足目标，不能证明所有第三模块都无效，也不能
仅凭平均指标断言具体是过拟合、背景混淆或损失冲突。部分方法调整末端分数，
可能更多改变阈值处的P/R平衡；新增表征也不保证与QLCS/DSQC互补。

本轮只读检查当前本地**训练/验证**标注得到：

- train：692图、574框、135张空标注图；val：202图、165框、39张空标注图。
- 均为512×512、单类hdc。验证集165框全属COCO large，面积占图中位数34.68%。
- 约70%的框至少一边贴近图边（≤1像素）；这不等于标注错误，可能与切片有关。
- 验证集一个TP变化就对应约0.61个百分点的R变化，少量预测变化会影响汇总结果。

因此不优先引入小目标P2分支，也不再扩大框外环带假设背景。本次选择在
P5→P4（16→32）、P4→P3（32→64）的语义/空间融合之前做对齐。这仅是与现有
任务更相关的待检验假设，并没有逐框证据证明“上采样错位”就是主要错误来源。

## 文献依据及命名边界

- [DySample，ICCV 2023](https://openaccess.thecvf.com/content/ICCV2023/html/Liu_Learning_to_Upsample_by_Learning_to_Sample_ICCV_2023_paper.html)：
  将动态上采样转为可学习位置的点采样，有检测实验和[作者实现](https://github.com/tiny-smart/dysample)。
  本模块的分组/子像素采样坐标布局由其实现适配，保留[MIT许可](licenses/DySample-MIT.txt)。
- [FreqFusion，TPAMI 2024](https://arxiv.org/abs/2408.12879)：
  研究跨层融合中的类别内不一致与边界偏移，通过滤波和重采样改善特征。
  本轮借鉴“融合前对齐”的方向，**没有复现其完整高低通滤波系统**。
- 也检索了[UPLiFT，CVPR 2026](https://openaccess.thecvf.com/content/CVPR2026/html/Walmer_UPLiFT_Efficient_Pixel-Dense_Feature_Upsampling_with_Local_Attenders_CVPR_2026_paper.html)
  的特征上采样方向，但其任务无关密集特征设定不直接等于当前D-FINE的检测FPN，
  本轮没有移植或宣称复现它。

CSGA是本项目的工程名称。区别于原始DySample的改动为：低层特征参与预测偏移、
有界偏移及零初始化的有界残差。是否构成有价值的方法贡献，需要和原始DySample、
无低层引导等对照验证，不能只换名字就写成原创算法。

## 计算路径

高层特征H为B×C×h×w，侧向低层特征L为B×C×2h×2w，默认C=256、分组g=4。

1. `offset = 0.25 * tanh(Conv_high(H) + PixelUnshuffle(Conv_low(L), 2))`。
   高层预测2×g×4通道，低层预测2×g通道并按四个子像素相位重排。
2. 将偏移加到双线性上采样的规则子像素坐标，分组GridSample高层特征得到A。
   偏移上限0.25以**粗特征像素**为单位，网格和采样用FP32，输出回到输入dtype。
3. `U = nearest(H) + 0.5*tanh(gate) * (A - nearest(H))`。
   gate按通道组广播、初始为0。它是可正可负的有界残差，**不是凸组合**，也不
   表示输出特征绝对值有界。
4. 原有 `concat(U, L) → FPN卷积融合 → PAN` 完全保留。

两路偏移卷积零初始化，此时A为双线性结果，与nearest在非常量特征上不同：
第一步gate有梯度，gate离开0后偏移分支开始学习，不是双重零初始化死分支。
初始输出与原QLCS+DSQC完全一致，新构造器隔离随机数消耗，保留共有参数初始化。

本模块改变共享特征，因此训练后可以同时影响分类与定位；不宣称只影响P。
低层纹理也可能带来噪声，边界采样使用border处理并不等于有完整图外语义。

## 本轮不变项与开关

- 不修改 `qlcs.py`、`dsqc.py`、decoder逻辑或criterion；QLCS层0～3，DSQC层3。
- 不冻结QLCS/DSQC权重；从相同官方预训练权重开始，正常联合训练。
- 不改数据划分、512输入、batch6、2e-4学习率、150轮、135轮停止增强、AMP。
- 从官方`dfine_m_obj2coco.pth`初始化，RESUME为空；不用旧双模块best权重续训。
- 当前种子3407，输出`output/qlcs_dsqc_csga/2e-4_SD3407`。换18/2026须换目录。
- 超参数都在`dfine_hgnetv2_m_qlcs_dsqc_csga.yml`；回退参照用`qlcs_dsqc`。
- `dsqc`独立模式未改。另一台电脑正在训练时，不要中途拉取/覆盖其源码配置。
- `valid.py`、`test.py`本轮未修改。它们的CHECKPOINT_PATH/输出目录仍是用户原值；
  评估新实验前必须改成对应CSGA权重，并保持统一best_map50选权重规则。

QCR、QACG、QFBCG、MGCA、SHEA全部关闭。设置文件补回旧归档模式映射，仅便于
复现，不意味着这些模块重新有效，也不会随当前模式自动启用。

## 开销与检查

新增20,568参数：QLCS+DSQC的19.684140M → 19.704708M（约+0.10%）。
CSGA在推理时也运行，不能声称无推理代价。calflops仍沿用现有部署图统计口径；
采样、访存和转换的实际代价须以同机测速为准，不能单凭卷积FLOPs代替延迟。
本次512输入部署图实测计数为40.761188G（双模块此前同口径约40.719163G）；
这不是延迟实测结果，表格中的FPS应等正式权重同机测速后填写。

新增训练日志 `csga_mix_0/1` 是每组残差系数的平均绝对值，`csga_offset_0/1`
是实际预测偏移的平均绝对值（粗网格像素单位）。采用科学计数显示小值，同时写入
TensorBoard和log.txt。它们不是损失项；数值非零只证明参与学习，不证明精度提高。

校验命令（不读真实数据、不保存训练权重）：

```powershell
python -m unittest discover -s my_improve/tests -p "test_csga.py" -v
python -m my_improve.tests.smoke_csga
```

覆盖坐标相位/分组、边界、梯度、AMP、零门等价、共有状态和完整512训练步骤。
本轮32项测试通过（14项CSGA新增测试、18项既有QCR/criterion回归测试），完整
512输入的两步FP32优化和一步CUDA AMP优化通过，双路偏移及gate都能更新。
随机初始化的完整模型会因部署融合后的近似并列top-k重新排序而出现逐查询差异；
脚本通过候选来源索引对齐，始终保持框/分数配对，本次对齐后分数最大差约
7.2e-7、框最大差约6.0e-8。同输入encoder、同memory decoder检查也通过。
以上只覆盖该合成输入检查，不能保证任意真实权重导出精度完全一致，
ONNX/TensorRT还需单独验证。

## 预先固定的实验判据

先跑3407，头5～10轮仅检查损失有限、分支是否学习，不以早期单轮精度决定成功。
首轮按150轮跑完并用相同验证best_map50规则评估，有潜力后保持同一配置补齐18、2026。
三种子同时报告，不能替换不好的种子，不能把调参前后混成一个均值。

参照是用户确认的QLCS+DSQC验证均值AP50=0.9224、P=0.8181、R=0.8869、F1=0.8509。
核心目标：AP50均值不下降、F1提高；期望F1至少+0.005、P至少+0.010，且至少
两个种子的P/F1同向改善，不能靠明显牺牲R换P。上述是工程目标，不是显著性检验。
失败则归档，成功再补相应独立/机制消融，不预先列为“有效第三创新点”。

## 实验来源核对事项

当前本地SD18双模块报告仍是旧版本0.9181/0.7861/0.8352（AP50/P/F1）；
用户确认的重训0.8973/0.8114/0.8353来自此前截图。不可把两者混为同一次。
本地SD3407训练日志最高AP50约0.923685，但验证报告0.927429引用G盘另一权重路径；
这不证明评估错了，却意味着不能直接把该本地日志当作报告权重的训练日志。
后续应留存每次权重、数据划分、配置、seed、epoch和文件哈希以确认来源一致。

继续设计/筛选只用训练和验证集，不用已查看的测试结果反复选择新模块。
